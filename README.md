# Империя и образ России в британской прессе, 1800–1919 гг.

Репозиторий содержит код, входные решения и воспроизводимые результаты **двух самостоятельных исторических исследований**, использующих двенадцать независимо обученных десятилетних моделей Word2Vec британской газетной коллекции проекта *Living with Machines*.

**Исходные модели:** N. Pedrazzini, *Decade-level Word2Vec models from automatically transcribed 19th-century newspapers digitised by the British Library (1800–1919)*, Zenodo, 2023. DOI: [10.5281/zenodo.7887305](https://doi.org/10.5281/zenodo.7887305).

Модели не выровнены между десятилетиями. Значения проекций исследуются преимущественно в сравнении слов **внутри одной модели**; соединяющие линии на рисунках служат для чтения серии десятилетних результатов, а не задают общую шкалу изменения значений слов.

## Исследования и ноутбуки

| Исследование | Файл | Назначение |
| --- | --- | --- |
| Общее | `00_prepare_data.ipynb` | Проверка готового кэша, параметры моделей и частоты. Полные модели нужны для перестройки кэша и дополнительных проверок `03_null_tests.ipynb`. |
| **Статья 1. Империя и империализм** | `01_imperial_lexicon.ipynb` | Частоты и ближайшие соседи имперской лексики; лексическая фильтрация и сопоставление британского и иностранного семантических полей. |
| **Статья 2. Россия в британской прессе** | `01_russia_neighbors.ipynb` | Соседи *russia*, *czar* и дополнительно *russian*: Top-100 → документированная проверка слов → Top-15. В статье используются *russia* и *czar*. |
| **Статья 2. Образ России в британской прессе** | `02_russia_axes.ipynb` | Две семантические оси, проекции одиннадцати названий, сравнение стран и проверки чувствительности. |
| **Статья 2. Образ России в британской прессе** | `03_null_tests.ipynb` | Случайные оси, расширенная группа названий государств и территорий, проверка частотной зависимости. |

Вторая статья — «Образ России в британской прессе 1800–1919 гг.: опыт векторного семантического анализа». Анализ соседей не изменяет векторы и не является входом расчёта осей. Ноутбук дополнительных проверок использует исходные модели (или отдельно подготовленный кэш) и сверяет основные разности и ранги с сохранённой таблицей.

## Быстрый запуск

Понадобятся Python 3.11+ и библиотеки из `requirements.txt`. Откройте Jupyter из корневого каталога Git-клона:

```bash
python -m pip install -r requirements.txt
python -m pip install jupyterlab
jupyter lab
```

**Основные расчёты по готовому кэшу:** выполните `00_prepare_data.ipynb`, затем `01_imperial_lexicon.ipynb` или `01_russia_neighbors.ipynb` и `02_russia_axes.ipynb` для соответствующего исследования. После установки зависимостей загрузка полных моделей для этих расчётов не требуется. `02_russia_axes.ipynb` сохраняет прежний набор рисунков и диагностические иллюстрации.

**Дополнительные проверки:** `03_null_tests.ipynb` требует полных моделей Pedrazzini (2023) либо ранее сформированного файла `data/cache_null/null_candidates.npz` (в репозитории отсутствует). Результаты проверок уже сохранены в `results/tables/06_*.csv`. См. [инструкцию по воспроизведению](docs/reproduction.md) и [дополнительные проверки](docs/robustness_checks.md).

**Рисунки окончательной редакции второй статьи:** из корня репозитория выполните:

```bash
python make_article_figures.py
```

Скрипт читает только три сохранённых CSV (разности и проекции по обеим осям), создаёт два рисунка в PNG (600 dpi) и SVG и не требует моделей или повторного выполнения ноутбуков. Готовые SVG включены в репозиторий.

**Важная оговорка:** `data/cache_2023/cache.pkl` — формат pickle. Не открывайте сторонние непроверенные файлы pickle; используйте поставляемый доверенный кэш проекта или перестраивайте его самостоятельно из оригинальных моделей.

При перестройке кэша используйте параметры и переменные окружения `00_prepare_data.ipynb` и `lwm/config.py`. Фактические параметры опубликованных файлов: размерность 200, окно 5, min_count 10, пять эпох; они отличаются от части параметров в описании набора на Zenodo.

## Входные данные

```text
data/cache_2023/cache.pkl                сохранённые векторы, соседства и сведения о моделях
ocr_decisions.csv                        экспертные лексические решения статьи 1
ocr_exclusions.csv                       точные правила исключения статьи 1
data/article2_neighbors/                 отдельная система решений статьи 2
    prior_lexical_decisions.csv
    target_variants.csv
    chat_review.csv
    author_decisions.csv
    *_source_top100.csv
    CHAT_PROMPT.md
```

**Статья 1** использует исходные правила из `ocr_decisions.csv` и `ocr_exclusions.csv`. **Статья 2** использует иную, явно описанную процедуру; предложения языковой модели получены в чате и сохранены в `chat_review.csv`, так что повторный API-вызов не требуется. Исторические формы и имена собственные не удаляются только по причине неизвестности современному словарю. Отдельно различаются вероятные OCR-артефакты и варианты самого целевого слова. Сохранение решений не означает проверки каждого газетного оригинала.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты первой статьи проверяют входной кэш, OCR-решения и воспроизведение опубликованных результатов. Для второй статьи итоговый Top-15 формируется из опубликованных исходных CSV и решений; проверяется число списков (36), число выбранных соседей (540) и отсутствие нерешённых словоформ до границы пятнадцатого соседа. Согласованность осей и чувствительность к составу пар и сравнительной группы проверяются в `02_russia_axes.ipynb`. В `03_null_tests.ipynb` дополнительно проверяются отклонения на случайных осях и положение России в расширенной группе. Эти проверки диагностические, без поправки на множественные сравнения и без повторного обучения моделей.

## Ограничения

Оцифрованный корпус газет не является репрезентативной выборкой общественного мнения. Из-за ошибок распознавания и полисемии сходство векторов нельзя непосредственно понимать как единую оценку страны. Сопоставление независимо обученных моделей остаётся описательным. Подробнее — в соответствующих публикациях и пояснениях внутри ноутбуков.
