# Империя, империализм и образ России в британской прессе 1800–1919 гг.

**Empire, Imperialism and the Representation of Russia in the British Press, 1800–1919**

Код, настройки и результаты расчётов для двух исторических исследований на основе десятилетних векторных моделей проекта Living with Machines:

1. **Империя и империализм в британской прессе 1800–1919 гг.: опыт диахронического векторного анализа** — частоты имперской лексики, её ближайшие соседи и относительная близость к британским и иностранным обозначениям.
2. **Образ России в британской прессе 1800–1919 гг.** — положение России на осях «деспотизм — свобода» и «варварство — цивилизация» в сравнении с другими странами.

Ссылки на опубликованные статьи будут добавлены после публикации. Данная редакция подготовлена на основе архива коммита `1ec110ebe0d32ba907d98fbcb3fc15d8e9b9008d`. Рукопись первой статьи: `empire_lexicon_v13.md`.

## Источник

Pedrazzini, N. (2023). *Decade-level Word2Vec models from automatically transcribed 19th-century newspapers digitised by the British Library (1800–1919).* Version 1. Zenodo. <https://doi.org/10.5281/zenodo.7887305>

Двенадцать моделей Word2Vec (skip-gram), по одной на десятилетие. Полные модели в репозиторий не включены (около 5,7 ГБ). В комплект входит небольшой кэш исходных векторов и соседей, достаточный для воспроизведения обеих статей.

Фактические параметры файлов: размерность 200, окно 5, минимальная частота 10, по 5 эпох и отрицательных примеров; словари от 137 888 до 428 930 записей; сумма `corpus_total_words` — 2 683 235 472. Они расходятся с описанием набора на Zenodo (размерность 100, минимальная частота 5, 4,2 млрд слов); в расчётах используются фактические значения (`results/tables/01_actual_model_parameters.csv`).

## Запуск

Рекомендуется Python 3.11 или новее; проверка выполнена на Python 3.13 (см. `docs/reproduction.md`). Для запуска с готовым кэшем многогигабайтные модели и сетевой доступ к Zenodo не нужны.

```bash
pip install -r requirements.txt
pip install jupyterlab
jupyter lab
```

**Обычный запуск:** откройте Jupyter из корня репозитория. Выполните ноутбуки по порядку:

1. `00_prepare_data.ipynb` — читает и проверяет поставляемый кэш, сохраняет сведения о моделях, таблицы и рисунок частот.
2. `01_imperial_lexicon.ipynb` — применяет сохранённые правила OCR, формирует соседей и отчёт первой статьи, рассчитывает баланс полей и строит рисунки. Дополнительные списки соседей и показатели `jingo` сохранены для совместимости с общим проектом.
3. `02_russia_axes.ipynb` — рассчитывает оси, проекции стран и проверки чувствительности второй статьи.

При наличии кэша ноутбуки 01 и 02 можно запускать непосредственно. При стандартном запуске файлы экспертных решений не изменяются. Орфографические подсказки по умолчанию отключены (`SPELL_DIAGNOSTICS = False`), поскольку они не влияют на фильтрацию. Включите их только для подготовки новой экспертной проверки.

**Перестройка кэша:** при изменении слов или параметров задайте `REBUILD_CACHE = True` в ноутбуке 00. Если кэш отсутствует, он создаётся автоматически; несовместимый кэш вызывает ошибку с указанием на необходимость явной перестройки. В этом режиме нужны полные модели (8–16 ГБ ОЗУ и около 10 ГБ диска). Если модели уже скачаны, укажите каталог через переменную окружения `LWM_MODEL_DIR_2023` до запуска Jupyter. При `VERIFY_AND_DOWNLOAD = True` ноутбук проверяет размеры и MD5 файлов Zenodo и скачивает только отсутствующие или повреждённые. При `False` проверяется наличие локальных файлов.

**Безопасность кэша:** `pickle` может исполнять код при загрузке. Используйте только поставляемый доверенный файл проекта или собственный кэш. SHA-256 поставляемого файла приведён в `docs/reproduction.md`.

**Технические тесты** (без моделей и без изменения результатов):

```bash
python -m unittest discover -s tests -v
```

## Методы первой статьи

**Слова.** *imperialism, imperialist, imperialists, imperial, empire, emperor, empress, jingoism*.

**Частоты.** Число употреблений из файлов моделей, на миллион токенов по `corpus_total_words`. Отсутствие слова в словаре отмечается пропуском, а не нулём.

**Ближайшие соседи.** Для каждой доступной словоформы и десятилетия извлечены 500 соседей. Орфографический словарь `pyspellchecker` 0.8.3 использовался как диагностический инструмент, а не как автоматический фильтр. Исключаются идентифицированные искажения, слитные и усечённые записи и нелексические токены. Имена собственные, исторические и иноязычные написания сохраняются. Решения приняты по облику записей и их окружению без сверки с газетными оригиналами. Фильтрация не затрагивает векторы и частоты.

**Экспертные данные и диагностика OCR.**

- `ocr_decisions.csv` — только 3 638 заполненных экспертных решений (`neighbor`, `decision`, `decision_reason`), перенесённых без изменения из прежнего `ocr_review.csv`. `exclude` задаёт глобальное исключение; `keep` подтверждает сохранение; `review` оставляет вопрос открытым. Для `keep` и `exclude` требуется обоснование.
- `ocr_exclusions.csv` — сохранённые правила точного совпадения (`period`, `target`, `neighbor`, `reason`), `*` означает все десятилетия или целевые слова. Прежние правила имеют приоритет; конфликт `keep` с действующим исключением останавливает запуск, а не разрешается молча.
- `results/tables/03_ocr_diagnostics.csv` и `03_ocr_priority.csv` — производные данные. Не редактируйте их как экспертные решения. При отключённой орфографической диагностике поля словарной проверки пусты (не вычислялись). Очередь содержит формы текущих Top-30 без окончательного решения. Чтобы завершить экспертную проверку, добавляйте или редактируйте записи в `ocr_decisions.csv`, затем повторите раздел 1 ноутбука 01. Неоднозначные локальные исключения вносите в `ocr_exclusions.csv`.
- `03_ocr_diagnostics_reference.csv` — сохранённый исходный снимок диагностики, включая ранее полученные орфографические подсказки. Он не является входным файлом.

Для первой статьи отобраны только `IMPERIAL_LEXICON_TARGETS` и десятилетия с частотой не ниже 50. Все 2 250 позиций итоговых списков имеют решение `keep`. Неизвестность словарю не означает ошибку OCR, а статус `keep` не гарантирует правильность распознавания каждой записи. Для дополнительных слов второй статьи нерешённые случаи сохраняются в очереди.

**Баланс полей.** Разность средних косинусных сходств слова с двумя наборами:

```text
B(w) = mean(cos(w, OWN)) − mean(cos(w, FOREIGN))
```

| Набор | Состав |
| --- | --- |
| Британский (`OWN`) | british, britain, colonies, colonial, india, canada, dominion, queen |
| Иностранный (`FOREIGN`) | france, french, napoleon, bonaparte, austria, austrian, russia, russian, turkey, ottoman, germany, german |
| Базовая линия (`BASE`) | kingdom, government, army, nation, crown |
| Альтернативный британский | britain, british, england, english |
| Альтернативный иностранный | france, french, austria, austrian, russia, russian, turkey, turkish, germany, german |

Положительное значение означает большую близость к британскому набору. Показатель описательный: статистическая оценка устойчивости не проводилась, а замена состава наборов смещает его в среднем на 0,04. Величина 0,04 используется как условный описательный ориентир для малых значений, а не как граница статистической значимости. Базовая линия характеризует выбранную государственную лексику, а не технический дрейф моделей.

**Порог частоты.** Если слово встречается в десятилетии менее 50 раз (`MIN_COUNT_INTERPRET`), баланс не рассчитывается, а соседи не интерпретируются.

## Методы второй статьи

Каждая ось задаётся десятью парами слов (состав в `lwm/config.py`); направление оси — нормированное среднее разностей векторов пар, проекция страны — косинусное сходство её названия с этим направлением. Россия сравнивается с десятью названиями: *france, austria, prussia, germany, turkey, spain, italy, england, britain, america*. Основные показатели — разность проекции России и среднего по остальным названиям и разрыв между Британией и Россией. Чувствительность проверяется исключением по одной паре и по одной стране. Оси строятся отдельно для каждого десятилетия и не образуют единой шкалы.

## Ограничения

Оцифрованные газетные коллекции неодинаково представляют регионы и типы изданий. Ошибки распознавания занижают частоты и влияют на контекстные связи. Модели объединяют разные значения одной словоформы, а десятилетняя группировка не позволяет выделить отдельное событие. Списки соседей показывают контекстные связи и не заменяют чтения газетных текстов. Результаты характеризуют язык оцифрованной прессы, а не убеждения её читателей.
