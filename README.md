# Империя, империализм и образ России в британской прессе 1800–1919 гг.

**Empire, Imperialism and the Representation of Russia in the British Press, 1800–1919**

Код, настройки и результаты расчётов для двух исторических исследований на основе десятилетних векторных моделей проекта Living with Machines:

1. **Империя и империализм в британской прессе 1800–1919 гг.: опыт диахронического векторного анализа** — частоты имперской лексики, её ближайшие соседи и относительная близость к британским и иностранным обозначениям.
2. **Образ России в британской прессе 1800–1919 гг.** — положение России на осях «деспотизм — свобода» и «варварство — цивилизация» в сравнении с другими странами.

Ссылки на статьи будут добавлены после публикации.

## Источник

Pedrazzini, N. (2023). *Decade-level Word2Vec models from automatically transcribed 19th-century newspapers digitised by the British Library (1800–1919).* Version 1. Zenodo. <https://doi.org/10.5281/zenodo.7887305>

Двенадцать моделей Word2Vec (skip-gram), по одной на десятилетие. Модели в репозиторий не включены (около 5,7 ГБ); их загружает первый ноутбук.

Фактические параметры файлов: размерность 200, окно 5, минимальная частота 10, по 5 эпох и отрицательных примеров; словари от 137 888 до 428 930 записей; сумма `corpus_total_words` — 2 683 235 472. Они расходятся с описанием набора на Zenodo (размерность 100, минимальная частота 5, 4,2 млрд слов); в расчётах используются фактические значения (`results/tables/01_actual_model_parameters.csv`).

## Запуск

Нужны Python 3.11 или 3.12, 8–16 ГБ оперативной памяти и около 10 ГБ на диске.

```bash
pip install -r requirements.txt
pip install jupyterlab
jupyter lab
```

Ноутбуки выполняются по порядку:

1. `00_prepare_data.ipynb` — проверяет и при необходимости загружает модели из Zenodo, строит кэш (`data/cache_2023/`) с векторами слов проекта, частотами и 500 ближайшими соседями целевых слов.
2. `01_imperial_lexicon.ipynb` — фильтрует списки соседей, рассчитывает баланс полей, строит таблицы и рисунки первой статьи. Здесь же извлекаются соседи слов о России для второй статьи.
3. `02_russia_axes.ipynb` — строит оси, проекции стран и проверки чувствительности.

Если модели уже скачаны, укажите каталог до запуска Jupyter в переменной окружения `LWM_MODEL_DIR_2023`. После изменения списка слов или числа соседей (`TOPN`) кэш нужно перестроить (`REBUILD_CACHE = True` в ноутбуке 00). Для проверки чисел и рисунков модели не нужны: достаточно готовых таблиц в `results/tables/`.

## Методы первой статьи

**Слова.** *imperialism, imperialist, imperialists, imperial, empire, emperor, empress, jingoism*.

**Частоты.** Число употреблений из файлов моделей, на миллион токенов по `corpus_total_words`. Отсутствие слова в словаре отмечается пропуском, а не нулём.

**Ближайшие соседи.** Модели обучены на автоматически распознанных текстах, и значительная часть соседей — искажённые записи. Для каждого слова и десятилетия извлекаются 500 соседей; несловарные формы (по `pyspellchecker` 0.8.3) просматриваются вручную, пока не наберутся 30 сохранённых. Исключаются искажения самого слова и названий стран, слитные и разорванные записи, числовые токены, искажения обычных слов. Имена собственные, исторические и иноязычные написания сохраняются. Решения приняты по облику формы, без сверки с газетными оригиналами, и записаны в `ocr_review.csv` (`exclude`, `keep`, `review` с обоснованием) и `ocr_exclusions.csv`. Фильтрация не затрагивает векторы и частоты.

**Баланс полей.** Разность средних косинусных сходств слова с двумя наборами:

```text
B(w) = mean(cos(w, OWN)) − mean(cos(w, FOREIGN))
```

| Набор | Состав |
| --- | --- |
| Британский (`OWN`) | british, britain, colonies, colonial, india, canada, dominion, queen |
| Иностранный (`FOREIGN`) | france, french, napoleon, bonaparte, austria, austrian, russia, russian, turkey, ottoman, germany, german |
| Базовая линия (`BASE`) | kingdom, government, army, nation, crown |
| Альтернативный британский | britain, british, england, english |
| Альтернативный иностранный | france, french, austria, austrian, russia, russian, turkey, turkish, germany, german |

Положительное значение означает большую близость к британскому набору. Показатель описательный: статистическая оценка устойчивости не проводилась, а замена состава наборов смещает его в среднем на 0,04. Значения меньше этой величины по модулю рассматриваются как равновесие.

**Порог частоты.** Если слово встречается в десятилетии менее 50 раз (`MIN_COUNT_INTERPRET`), баланс не рассчитывается, а соседи не интерпретируются.

## Методы второй статьи

Каждая ось задаётся десятью парами слов (состав в `lwm/config.py`); направление оси — нормированное среднее разностей векторов пар, проекция страны — косинусное сходство её названия с этим направлением. Россия сравнивается с десятью названиями: *france, austria, prussia, germany, turkey, spain, italy, england, britain, america*. Основные показатели — разность проекции России и среднего по остальным названиям и разрыв между Британией и Россией. Чувствительность проверяется исключением по одной паре и по одной стране. Оси строятся отдельно для каждого десятилетия и не образуют единой шкалы.

## Ограничения

Оцифрованные газетные коллекции неодинаково представляют регионы и типы изданий. Ошибки распознавания занижают частоты и влияют на контекстные связи. Модели объединяют разные значения одной словоформы, а десятилетняя группировка не позволяет выделить отдельное событие. Списки соседей показывают контекстные связи и не заменяют чтения газетных текстов. Результаты характеризуют язык оцифрованной прессы, а не убеждения её читателей.
