# Империя своя и чужая

**Понятие империи и образ России в британской прессе 1800–1919 гг. по данным диахронических векторных моделей**

Вычислительное приложение к историческому исследованию. Самостоятельная версия на основе набора моделей Nilo Pedrazzini (2023). Все расчёты проводятся внутри модели отдельного десятилетия; выравнивание векторных пространств не требуется. Исходные модели не модифицируются.

## 1. Данные

Pedrazzini, N. (2023). *Decade-level Word2Vec models from automatically transcribed 19th-century newspapers digitised by the British Library (1800–1919)*. Zenodo. [DOI: 10.5281/zenodo.7887305](https://doi.org/10.5281/zenodo.7887305). Лицензия данных CC BY 4.0. Проект [Living with Machines](https://livingwithmachines.ac.uk/).

Используются полные модели с отдельными словарями для каждого десятилетия. Это позволяет исследовать политические термины, отсутствующие в опубликованном наборе с сокращёнными словарями (в частности, *imperialism*, *imperialist*, *jingoism*), и извлекать сохранённые частоты слов. Отсутствие словоформы в модели не означает отсутствия соответствующих употреблений в газете.

Фактические параметры всех двенадцати моделей по метаданным Word2Vec, полученным при предыдущем запуске на опубликованных файлах:

| Параметр | Значение |
|---|---:|
| Архитектура | Skip-gram (`sg=1`) |
| Размерность | 200 |
| `min_count` | 10 |
| `window` | 5 |
| `epochs` | 5 |
| `negative` | 5 |
| Сумма `corpus_total_words` | 2 683 235 472 |

Описание Zenodo указывает `vector_size=100`, `min_count=5` и корпус в 4,2 млрд слов. Эти сведения не совпадают с сохранёнными метаданными. В исследовании необходимо различать заявленный объём коллекции и число токенов, зарегистрированное в моделях при построении словарей. Ноутбук 00 извлекает фактические параметры автоматически и сохраняет их в `01_actual_model_parameters.csv`; размерность проверяется при загрузке. Данные о числе токенов и частотах относятся к распознанным текстам, а не к исправленному корпусу. Известны ошибки OCR; исходные модели не очищаются, исключения применяются только к спискам соседей.

## 2. Локальный запуск (Windows)

Рекомендуется Python 3.11/3.12 и не менее 8–16 ГБ RAM; GPU не требуется. Полный набор моделей занимает около 5,7 ГБ; желательно не менее 8–10 ГБ свободного дискового пространства при первичном скачивании.

Распакуйте архив в новый каталог (или обновите файлы прежнего репозитория, сохранив модели). Откройте PowerShell в корне проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install jupyterlab
.\.venv\Scripts\python.exe -m jupyterlab
```

Можно использовать ранее созданное окружение с теми же зависимостями. Если модели уже скачаны и находятся в `data/models_2023/` текущего репозитория, ничего переносить не нужно. Если они находятся в другом каталоге, задайте перед запуском JupyterLab:

```powershell
$env:LWM_MODEL_DIR_2023 = "D:\Research\models\LWM_2023"
.\.venv\Scripts\python.exe -m jupyterlab
```

Замените путь фактическим. Для каждой модели нужны три файла, например `1800s.model`, `1800s.model.wv.vectors.npy`, `1800s.model.syn1neg.npy`: стандартный загрузчик полной Word2Vec-модели читает все три. Ноутбук 00 проверяет размеры и MD5 по Zenodo и скачивает только отсутствующие или повреждённые файлы. Если все файлы ранее проверены и доступ к интернету не нужен, установите `VERIFY_AND_DOWNLOAD = False` в ноутбуке 00 (проверяется наличие, не контрольная сумма).

**При обновлении прежней версии:** закройте ядра Jupyter, замените три ноутбука, `lwm/`, `README.md`, `requirements.txt`, `ocr_exclusions.csv`; старые результаты лучше вынести в отдельный архив, чтобы не смешивать их с новыми. Удалите из рабочего проекта прежний сравнительный ноутбук и каталог с прежним набором результатов. Сохраните `data/models_2023/`, если модели там. Перестройте кэш: формат изменён, добавлены слова и увеличено число соседей. `REBUILD_CACHE = True` обязательно для первого запуска этой версии. Файлы моделей не скачиваются заново, если проходят проверку.

## 3. Ноутбуки и результаты

Запускайте по порядку 00 → 01 → 02. Файлы результатов создаются в `results/tables` (CSV, UTF-8 BOM) и `results/figures` (PNG, 300 dpi). Векторы, частоты и Top-200 сохраняются в `data/cache_2023/cache.pkl`. Последующие ноутбуки используют только этот кэш; при изменении правил OCR перестраивать его не нужно. При добавлении целевых или опорных слов кэш необходимо перестроить. В архив исходных моделей, кэша и результатов прежних экспериментов нет.

### 00_prepare_data.ipynb — источниковая база

- Проверка и при необходимости загрузка 36 файлов. Последовательная обработка моделей с `mmap="r"`.
- Метаданные, словари и частоты: `01_actual_model_parameters.csv`, `01_model_metadata.csv`, `01_vocabulary_project_words.csv`, `01_vocabulary_probe.csv`, `01_word_frequencies.csv`.
- `count` — сохранённая частота; `per_million_corpus` — на миллион `corpus_total_words`; `per_million_retained` — на миллион токенов, представленных в словаре. Знаменатели не смешивать. Недоступные значения — пропуски, не нули. График `01_key_word_frequencies.png`.

### 01_imperial_lexicon.ipynb — имперская лексика

Центральные слова: *imperialism, imperialist, imperialists, jingoism*; общая лексика *imperial, empire*; титулатура *emperor, empress*; дополнительно *jingo* и слова о России для анализа окружения.

**Соседи и OCR.** Исходные 200 кандидатов сохраняются с косинусным сходством и рангом. В `ocr_exclusions.csv` — ручные правила исключения точных словоформ, с обоснованием. Столбцы `period,target,neighbor,reason`: `*` допускается в `period` и `target`. Начальный список касается очевидных искажений в окружении *imperial*; это не исчерпывающая очистка. Для уточнения откройте `03_neighbors_review.csv`, просмотрите исходные и оставшиеся слова, добавьте правила и повторите только ноутбук 01. Не удаляйте автоматически исторические имена, редкие слова и варианты орфографии. Сохраняются `03_neighbors_raw_top30.csv`, `03_neighbors_filtered_top30.csv`, `03_neighbors_coverage.csv`, отдельные широкие таблицы для каждого целевого слова. Если в оставшемся списке ещё встречаются OCR-ошибки, их надо отметить вручную. Если остаётся меньше 30 кандидатов, искусственно список не дополняется.

**Баланс полей.** Для нормированных векторов `B(w) = mean(cos(w, OWN)) - mean(cos(w, FOREIGN))`. Основные наборы фиксированы в `lwm/config.py`. Положительное значение — большая средняя близость к британскому набору, а не доля британских референтов или одобрение империи. Сохраняются баланс всех девяти целевых слов, базовая линия пяти слов государственной лексики, отклонение от неё: `04_empire_balance.csv`, `04_empire_balance_minus_baseline.csv`. Пропуски для отсутствующих целевых слов сохраняются.

**Проверка чувствительности.** Альтернативные однородные поля `OWN_GEOGRAPHIC`, `FOREIGN_GEOGRAPHIC`: названия стран и соответствующие прилагательные, без колониальных обозначений и имён монархов. Словоформы *english* и *turkish* включены явно. Основной набор не заменяется. `04_geographic_balance.csv`, `04_geographic_balance_minus_baseline.csv`, `04_field_sensitivity.csv`. Базовая линия пересчитывается отдельно. Сопоставляются величина, знак и динамика; это не статистический тест. Рисунки `fig1_political_lexicon_balance.png`, `fig1_imperial_balance.png`, `04_political_balance_minus_baseline.png` и рисунки альтернативных полей.

### 02_russia_axes.ipynb — образ России

Две рабочие оси (по десять пар): «деспотизм — свобода», «варварство — цивилизация». Ось — нормированное среднее нормированных направлений от отрицательного к положительному слову пары. Используются единичные векторы слов. Положение названия страны — скалярное произведение с единичной осью. Основные пары и десять контрольных названий неизменны. Ось «восток — запад» только диагностическая.

**Согласованность.** Среднее попарное косинусное сходство направлений. Для диагностики исходных списков разрешены пропуски: пара с недоступным словом не участвует в расчёте данного периода, её собственная оценка — NaN; число доступных пар и десятилетий записывается. В частности, `uncivilized` отсутствует в 1910-х и входит только в исключённую пару. Для рабочих осей требуется наличие всех обязательных слов, автоматическая замена не производится. Таблицы `02_pair_availability.csv`, `02_pair_parallelism_*.csv`, `02_pair_summary_*.csv`, `02_axes_reliability.csv` и диагностические рисунки.

**Основные показатели.** Проекции стран и ранги (`05_projections_*.csv`, `05_order_*.csv`), Россия минус среднее остальных десяти названий (`05_russia_minus_others.csv`), прямой разрыв Britain–Russia (`05_britain_russia.csv`), рисунки 2 и 3. Относительные проекции не являются долей негативных оценок или опросом общественного мнения. Ранги 1 = самая низкая проекция.

**Проверки чувствительности.** Последовательное исключение каждой рабочей пары (9 вместо 10): `05_leave_one_pair_out.csv` (240 вариантов), `05_leave_one_pair_summary.csv` (24 строки), `05_axis_pair_sensitivity.png`. Диапазоны — минимумы/максимумы вариантов, не доверительные интервалы. Рассчитываются также смены знака и разрыв Britain–Russia. Отдельно исключаются по одному контрольные названия, а также Турция; Германия и Пруссия; Англия и Пруссия (снижение веса пересекающихся обозначений). Все сценарии для всех десятилетий: `05_country_group_sensitivity.csv`. Исходные проекции не меняются.

## 4. Настройки и воспроизводимость

```
00_prepare_data.ipynb
01_imperial_lexicon.ipynb
02_russia_axes.ipynb
lwm/config.py              # слова, поля, пары, страны, пути
lwm/tools.py               # загрузка, кэш, меры, сохранение
ocr_exclusions.csv         # редактируемые ручные правила
requirements.txt
results/tables/
results/figures/
```

Параметры задаются в `lwm/config.py`. Все количественные показатели рассчитываются на неизменённых векторах исходных моделей. Фильтрация соседей не влияет на баланс или оси. Проверки чувствительности не используются для автоматического подбора наиболее удобного результата. Исследование характеризует контекстные связи слов в газетах, а не непосредственное общественное мнение. Историческая интерпретация требует источниковедческой проверки, особенно для низкочастотных слов и политических событий внутри десятилетий.

После завершения сохраните архив только папки `results` (и `ocr_exclusions.csv`, если правили правила). Из корня проекта в PowerShell:

```powershell
Compress-Archive -Path results,ocr_exclusions.csv -DestinationPath results_empire_final.zip -Force
```
