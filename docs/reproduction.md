# Воспроизведение результатов

Входные модели: Pedrazzini 2023, Zenodo 7887305. Готовый доверенный кэш расположен в `data/cache_2023/cache.pkl`. SHA-256 кэша из исходной проверки проекта: `97ba07c16cb7b530d19f9f06a6680a4c4c21b785a2d601632ae66e1aa16f6e5a`. При чистом клонировании следует самостоятельно проверить этот SHA и запускаемые ноутбуки.

Текущий рабочий процесс содержит четыре ноутбука: `00_prepare_data.ipynb`, `01_imperial_lexicon.ipynb`, `01_russia_neighbors.ipynb`, `02_russia_axes.ipynb`. Для второй статьи обязательны входные файлы из `data/article2_neighbors/`. Вызовы LLM в коде не выполняются; сохранённые решения воспроизводят проведённую предварительную классификацию.

Последовательность проверки:

1. Установить зависимости из `requirements.txt` и запустить `python -m unittest discover -s tests -v`.
2. Выполнить `00_prepare_data.ipynb` в режиме повторного использования готового кэша; перепроверить параметры и частоты.
3. Выполнить `01_imperial_lexicon.ipynb`; сверить первую статью по `03_neighbors_article1_top30.csv` и `04_empire_balance.csv`.
4. Выполнить `01_russia_neighbors.ipynb`; убедиться в наличии 36 списков по 15 слов и сверить `results/article2_neighbors/top15_long.csv`.
5. Выполнить `02_russia_axes.ipynb`; сверить `05_projections_*`, `05_russia_minus_others.csv`, `05_table4_for_article.csv`; проверить три публикационных рисунка и их сохранённые выводы в самом ноутбуке.

Параметры Word2Vec и ограничения междесятилетней сопоставимости описаны в README и статьях. Кэш — pickle и может выполнять произвольный код при загрузке: не используйте сторонние неподтверждённые pickle-файлы.

**Внимание:** второй этап очистки, предусматривающий удаление `03_neighbors_review.csv`, потребует изменения `tests/test_ocr.py` **до удаления**. До этой правки файл следует сохранить.
