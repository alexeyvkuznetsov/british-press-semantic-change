# Воспроизведение результатов

Входные модели: Pedrazzini 2023, Zenodo 7887305. Готовый доверенный кэш расположен в `data/cache_2023/cache.pkl`. SHA-256 кэша из исходной проверки проекта: `97ba07c16cb7b530d19f9f06a6680a4c4c21b785a2d601632ae66e1aa16f6e5a`. При чистом клонировании следует самостоятельно проверить этот SHA и запускаемые ноутбуки.

Текущий рабочий процесс содержит пять ноутбуков: `00_prepare_data.ipynb`, `01_imperial_lexicon.ipynb`, `01_russia_neighbors.ipynb`, `02_russia_axes.ipynb`, `03_null_tests.ipynb`. Для второй статьи обязательны входные файлы из `data/article2_neighbors/`. Вызовы LLM в коде не выполняются; сохранённые решения воспроизводят проведённую предварительную классификацию.

Последовательность проверки:

1. Установить зависимости из `requirements.txt` и запустить `python -m unittest discover -s tests -v`.
2. Выполнить `00_prepare_data.ipynb` в режиме повторного использования готового кэша; перепроверить параметры и частоты.
3. Выполнить `01_imperial_lexicon.ipynb`; сверить первую статью по `03_neighbors_article1_top30.csv` и `04_empire_balance.csv`.
4. Выполнить `01_russia_neighbors.ipynb`; убедиться в наличии 36 списков по 15 слов и сверить `results/article2_neighbors/top15_long.csv`.
5. Выполнить `02_russia_axes.ipynb`; сверить `05_projections_*`, `05_russia_minus_others.csv`, `05_table4_for_article.csv`. Последнее имя относится к прежней нумерации: в окончательной редакции второй статьи разности и ранги приведены в таблице 2. Ноутбук сохраняет прежние рисунки и дополнительные диагностики.
6. Для построения двух окончательных рисунков выполнить из корня `python make_article_figures.py`. Скрипт использует `05_russia_minus_others.csv`, `05_projections_liberty.csv`, `05_projections_civilisation.csv`. Результаты: `results/figures/fig1_russia_relative_article.{png,svg}` и `results/figures/fig2_countries_two_axes_article.{png,svg}`; готовые SVG имеются в Git. Горизонтальные смещения точек на рисунке 2 предназначены только для различимости, значения проекций не меняются.
7. Для независимого повторения дополнительных проверок выполнить `03_null_tests.ipynb`. Нужны двенадцать исходных моделей с сопутствующими файлами либо ранее созданный `data/cache_null/null_candidates.npz`, которого нет в Git. Путь к моделям можно задать переменной `LWM_MODEL_DIR_2023` до запуска. Ноутбук использует seed 20261122, 4000 наборов на вариант и ось, минимальную частоту 50, семантическую окрестность из 2500 слов и словарный фильтр `pyspellchecker` (см. параметры ноутбука). Установите все зависимости из `requirements.txt`; обычный `cache.pkl` недостаточен. Сверить `06_null_aggregate.csv`, `06_null_per_decade.csv`, `06_wide_states.csv` и `06_null_band.png`. Подробнее см. [дополнительные проверки](robustness_checks.md).

Шаги 2–5 можно выполнить по обычному доверенному кэшу, шаг 6 — только по CSV. Шаг 7 требует полных моделей или специального кэша; сохранённые результаты доступны и без него.

Параметры Word2Vec и ограничения междесятилетней сопоставимости описаны в README и статьях. Кэш — pickle и может выполнять произвольный код при загрузке: не используйте сторонние неподтверждённые pickle-файлы.

**Внимание:** второй этап очистки, предусматривающий удаление `03_neighbors_review.csv`, потребует изменения `tests/test_ocr.py` **до удаления**. До этой правки файл следует сохранить.
